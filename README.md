# Версия 90

Замените файлы из архива поверх версии 89. Архив содержит только изменённые и новые файлы.

## Размещение моделей на сайте

Рядом с index.html должна быть папка models/ со следующими файлами:
- plate_det.onnx
- paddle_det.onnx
- paddle_rec.onnx
- meter_detector.onnx
- meter_fast_ocr.onnx

Актуальный присланный meter_detector.onnx включён в архив в папке models/. Остальные четыре файла используйте из прежнего комплекта моделей: если они уже есть на сайте, повторно выкладывать их не требуется. Установленные модели сохраняются на телефоне для офлайн-работы.

При первом распознавании на новом телефоне потребуется доступ к сайту для загрузки моделей. Приложение не запрашивает выбор файлов с телефона.

## Обновления

Кнопка проверки обновления сохранена. Автоматическая проверка выполняется при открытом приложении не чаще одного раза в 14 дней, без уведомлений при отсутствии новой версии или сети. При закрытом приложении проверки не выполняются.

Полный список изменений в CHANGES.md.
