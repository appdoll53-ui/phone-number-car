# Версия 94

- При новой версии приложения модели повторно загружаются. Перед заменой проверяются файлы и запуск. При неудаче остаётся сохранённая модель, попытка повторяется при возвращении интернета.
- Присланная новая модель поиска точки включена в models/meter_detector.onnx.
- Разделитель сопоставляется со всеми цифрами: маленькая точка между цифрами отделяет целую часть; охватывающая метка включает охваченный разряд в дробную часть. Поддерживаются несколько дробных разрядов. При противоречивых результатах требуется ручная проверка.
